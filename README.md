# 🧮 Algorithm Hub

An interactive algorithm learning platform and problem-solving journal.

## 🌐 Live Site

Visit: [Algorithm Hub](https://tuanhalo.github.io/Algorithm/)

## 📚 What's Inside

### Teaching Hub (`/learn/`)
Interactive algorithm lessons organized by topic, featuring:
- Step-by-step visual simulations you can interact with
- Clean Python implementations
- Complexity analysis with visual comparisons

### Problem Journal (`/problems/`)
Solutions to LeetCode, HackerRank, and other platform problems with:
- My approach and solution code
- AI-generated feedback (strengths, improvements, edge cases)
- Visual walkthroughs of solution logic

## 🛠️ Development

```bash
pnpm install
pnpm dev        # Start dev server at localhost:4321
pnpm build      # Build for production
pnpm preview    # Preview production build
```

## 📖 Style

Built with [Astro](https://astro.build) using **Claymorphism** design — soft, rounded, tactile UI elements that feel friendly and approachable.
